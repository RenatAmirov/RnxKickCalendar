# Календарик-пинарик

Десктопный календарь на F# и WPF для Windows. В основе лежит упражнение Дмитрия Литвака, описанное Глебом Архангельским. [«Тайм-драйв», раздел «Календарик-пинарик»](https://asproplus.com/Books/arhangelsky-time_drive.pdf#page=34)

## Как пользоваться

1. В настройках укажите год рождения и последний год на личной шкале. По умолчанию шкала показывает 30 будущих лет.
2. Щёлкните по прошедшему дню или году, чтобы зачеркнуть его. Повторный щелчок снимет отметку.
3. Для сегодняшнего дня первая отметка закрашивает половину клетки, а вторая зачёркивает её целиком. Правый щелчок по клетке или кнопка «Снять отметку» сбрасывает отметку.
4. Запишите цели для выбранного года. Они сохраняются автоматически. Кнопка «Поверх окон» закрепляет календарь на экране.

Отметки, цели и настройки хранятся в `%LOCALAPPDATA%\RnxKickCalendar\calendar.json`.

## Запуск из исходников

На Windows с установленным .NET 10 SDK выполните из папки проекта:

```powershell
dotnet run --project .\RnxKickCalendar.fsproj
```
